# 航线相机参数匹配与提示

更新：2026-09-25。适用于本次相机提示修复及后续版本。

## 自动识别与参数估算

- 根据飞机、相机和镜头名称匹配公开规格中的照片尺寸、视场角及拍照间隔，不代表逐台相机光学校准或逐机实飞验收。
- 未收录或未知负载不冒充已确认的广角相机，规划参数明确标为估算。单纯没有参数目录条目，不再禁止执行。
- 照片比例、分辨率、变焦和支持的横竖拍读回用于判断参数可信度；V5 保留 16:9 中心裁剪规划。

## 执行行为

- 参数暂缺、过期或与航线几何不同，只提示覆盖率/GSD可能不准；不阻止开始或恢复，不自动暂停正在执行的航线，包括 V5 原生 KMZ。没有新增确认按钮。
- 云端补拍导入采用同样逻辑：几何/照片比例差异属于提示，不混在阻断原因中；不会悄悄改写航点、航高或速度。
- 相机断连/不可拍照、KMZ 无法映射的负载，以及真实的拍照/飞行失败仍按原逻辑处理。遥控接管、飞行遥测过期、电量、高度、控制权等保护不变。
- V5 在 KMZ 准备时尝试设置规划照片比例；该几何偏好设置失败记为提示，不能冒充设置成功。实际上传和执行仍必须由 SDK 成功接受。
- 明确启用的 UE HIL 虚拟图像源不依赖物理相机几何确认。

## 参数缓存修复

- 每个参数最多每秒请求一次。刷新失败不立即删除仍在有效期内的成功值，但绝不刷新其时间戳或无限沿用，原两秒有效窗口不变。
- Android 改为回调之后再计算数据年龄，修复“成功回调跨过一毫秒，刚读到的数据反而无效”的问题。
- 换相机、断连或会话切换仍清空缓存，旧会话迟到回调不能恢复旧值；过期数据不会被标为已确认。

## 换机使用

需要可靠重叠率/GSD时，使用真实镜头、比例和变焦参数；与原规划视场不同时应重新生成本地或工作站任务。参数估算可能造成覆盖空洞或比例误差。允许执行并不保证测绘质量，也不承诺所有 DJI 支持的负载均已适配。

本次没有新增自动标定能力、改动机型支持或代替地面拍照及人工监督实飞验证。软件回归使用假飞控/桌面模拟器，不等于真实飞行验收。
